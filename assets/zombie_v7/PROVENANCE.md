# Provenance

The body is the MakeHuman 1.x base mesh (`base.obj`), which the MakeHuman project released as CC0. No MakeHuman application code is included. Only the mesh was used, then edited.

- Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
- License: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md (section C, assets are CC0 1.0)
- Copyright holders named on the mesh at the CC0 release: Data Collection AB, Joel Palmius, Jonas Hauquier

The file header says the asset was explicitly released as CC0 in September 2020.

Kael's own mesh was not used as the body. It is the clothed hero, robe and cape included, and that cape is what stretches on the kael clips. The skeleton and the clips are the project's, from `voxel/kael_voxel.glb`.

The clothing is not the TRELLIS shell. Each garment is a quad strip built around the body: a torso tube, arm tubes, a back panel, skirt panels, a belt, a strap, shin tubes, and, on the soldier, a shoulder plate and a knee plate. The TRELLIS shells in `assets/zombie_src/` were the colour reference for the grey-brown, red, and blue, not the mesh. Those shells are generated imagery, not a CC0 scan.
